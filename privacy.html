Política de Privacidade – Sune

Última atualização: 12 de outubro de 2026.

Quem somos

Sune é um assistente pessoal operado por Hugo Lima (cpthugolima@gmail.com), para uso próprio.

Dados acessados

Mediante autorização via Google OAuth, o aplicativo acessa o Google Agenda (leitura e criação de eventos) e o Gmail (leitura e organização de mensagens) da conta do próprio usuário, apenas para executar as tarefas que ele solicitar.

Uso dos dados

Os dados do Google são usados exclusivamente para fornecer as funções do assistente ao usuário. Não são vendidos, compartilhados com terceiros, usados para publicidade ou para treinar modelos de IA de uso geral. O conteúdo necessário para responder a um pedido pode ser enviado temporariamente a um provedor de modelo de linguagem apenas para gerar a resposta daquele pedido.

Armazenamento e segurança

Os tokens de acesso ficam armazenados em servidor privado, com acesso restrito e protegido por autenticação. Nenhum dado do Google é publicado.

Revogação e exclusão

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Para solicitar a exclusão de dados armazenados, escreva para cpthugolima@gmail.com.

Conformidade com a Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
